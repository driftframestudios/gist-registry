# Registry artifact schema 0.1.0

This is the first experimental shared envelope derived from one real code
sample and the reusable anatomy of Practitioner Probes. Its canonical identity
is `https://kindlight.io/schemas/gist-registry/0.1.0/registry-artifact.schema.json`.
The URL is both the intended identity and an observed signed-out retrieval
route; the delivery-observation family carries that request's source,
projection, media-type, and digest evidence.

The schema deliberately leaves `artifactKind` open, distinguishes declared
representation media types from hosted observations, and provides an
`extensions` object for bounded learning. Issue #4 receives this experiment
and the observations that will eventually support a stable exact-version
contract. The runnable document-evidence sample and its compact code-excerpt
companion now exercise two artifact kinds without changing the shared envelope.
