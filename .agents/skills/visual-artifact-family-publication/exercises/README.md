# Exercise: admit and publish one visual family

Run:

```sh
node .agents/skills/visual-artifact-family-publication/exercises/exercise.mjs
```

The exercise checks source ownership, rights, intrinsic dimensions, three
responsive targets, distinct alternative text and caption, unique SVG IDs,
resolved local references, connector-before-card painter order, and one
accepted family receipt.

Recovery example: repeat `id="arrow"` in the SVG. Admission returns the
identity collision before publication while the expected accepted coordinate
remains the recovery point.
