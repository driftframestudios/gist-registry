# Equivalent evidence, distinct administrative context

Run the [standard-library exercise](exercise.py) with Python 3.11 or later:

```sh
python3 .agents/skills/controlled-context-comparison/exercises/exercise.py
```

Two arms receive the same authored measurement bytes and threshold. Their review
status changes from pending to approved. Literal expected results require the
scientific classification to agree and the administrative workflow to differ.
An unchanged-input repeat, a comparator that always reports agreement, altered
source evidence, and an incomplete pair provide distinguishing controls.

The outcome example retains two attempted arms and one observed result; its
failed arm prevents claiming complete paired agreement. It does not estimate a
population rate. The observer is deterministic and invokes no external model,
data, service, or authorized operational effect.

This receiving exercise applies the candidate instructions during the Registry
refinement task. Execution and independent review are recorded by the receiving
pull request. A natural receiving study can add its exact source, intervention,
controls, outcome accounting, and bounded inference there. Repetition of this
fixture establishes stable local behavior, while broad effectiveness and causal
claims retain their own designs.
