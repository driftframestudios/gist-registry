# Probe-bearing exemplar formation

Use this skill to turn one consequential technical question into a first
reviewable registry coordinate with a runnable or inspectable representation,
focused evidence, clear provenance, and a named continuation route.

## Fastest start

1. Read the [skill contract](SKILL.md).
2. Name the practical question, intended reader, changed ability, source owner,
   artifact kind, and observation that could change the claim.
3. Select the smallest representation that preserves the material mechanism,
   state, boundary, and recovery relationship.
4. Apply the matching proof route in
   [formation evidence and recovery](references/formation-evidence-and-recovery.md).
5. Return the candidate for review with its evidence standing, transfer
   boundary, recovery move, and next receiver.

## Success example

A pending-outbox query depends on tenant scope and the meaning of an
undelivered row. Its first package carries synthetic representative rows, the
explicit predicates, independently derived expected counts, and a deliberate
predicate perturbation. The README explains what the example establishes and
routes broader authorization, workload, and production recovery to focused
receiving checks.

## Recovery example

A decisive check exposes a count mismatch. Formation keeps the runnable source,
smallest counterexample, runtime coordinate, and current veracity standing. The
behavior owner repairs the query or narrows the claim; companions derive again
only after the affected proof passes.

## Evidence maturity and transfer boundary

This is a formation contract with authored review cases. Each resulting
artifact states its own `technicalVeracity` from actual source and behavior
evidence. Repository acceptance, immutable tagging, Pages delivery, optional
Gist publication, production suitability, and policy remain distinct decisions
with their established owners.
