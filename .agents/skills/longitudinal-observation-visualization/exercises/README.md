# Follow the observed support

The receiving question is: **which observations of A and B support a trajectory,
and where does an expected visit remain missing?** Five synthetic records
include unequal time intervals, an observed zero, an explicit missing visit,
and a singleton unit. Dates have day precision in one authored civil calendar;
the fixture makes no sub-day time-zone claim.

With Python 3.11 or later and its standard library:

```sh
python3 .agents/skills/longitudinal-observation-visualization/exercises/exercise.py --check
```

[readable figure and native table](example.html), [standalone SVG](example.svg), [exact values](values.csv), and
[expected segment companion](expected-segments.json) form one package. Omit
`--check` to regenerate, or use `--output DIRECTORY` for an independent copy.
The code first checks literal expected segments, then compares generated bytes.

The executable counterexamples distinguish dropping missing rows before
segmentation, connecting across identities, treating elapsed dates as equal
steps, sorting a returning paired-measure path by x, accepting unresolved time
ties, and changing the summary's weighting. The simple weighting calculation
illustrates two estimands; it supplies no general statistical estimator.

Inspect the HTML at full size and a narrow reading width. The zero at the
baseline, B's square, A's final isolated circle, date labels, missing-visit
annotation, and source/caption must remain available. The focusable figure/table
regions scroll locally at narrow widths; labels retain their authored size.
A full-size opening, native table, and CSV supply complementary reading routes.
