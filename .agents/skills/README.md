# Registry skills

Start with a concrete job, read one contract, and run its smallest exercise.
A skill guides attention and action; source, actual observations and the
receiving team's decisions establish the result. Each published package
includes its references and declared exercise files.

## Choose the first useful move

1. **Shape a scientific view.** Read [visualization question routing](visualization-question-routing/SKILL.md), identify the observation unit and the reader's comparison, then select one domain skill below. Keep original values and value states available beside the picture.
2. **Repair a runtime boundary.** Choose typed errors, resource ownership, admission or transaction mapping according to the operation's actual failure. Bring the source, an independent expected result and one counterexample.
3. **Compare alternatives.** Use controlled context for the comparison contract and parity-bound measurement for equivalent work. Run the [SQL measurement exercise](../../snippets/postgresql-pending-outbox-query/0.1.0/exercises/parity-bound-query-plans.md) for a concrete receiving example.
4. **Keep a useful result.** Exemplar formation creates the first version; versioned successors preserve an accepted coordinate while new evidence strengthens the next one.

## How the contracts formed

The first skills formed from the registry's initial lived collaboration and
the Practitioner Probe source family:
the [document-evidence artifact](../../snippets/document-evidence-extraction/README.md)
received several bounded architectural vantages, its demonstrated guarantee
became more precise, and accepted `0.1.0` bytes stayed intact. The immutable
`0.1.1` successor now carries the materially stronger source and test
architecture while its manifest records candidate maturity. [Exact excerpt
companions](../../snippets/document-evidence-core-patterns/README.md) make both
accepted behavior boundaries easier to inspect: `0.1.0` carries the initial
same-byte and single-failure patterns, while `0.1.1` carries observed-effect
reconciliation and caller-retained recovery. The skills preserve that
collaboration shape for another team while technical authority stays with the
artifact's source and focused tests.

The first-coordinate formation route carries the transferable probe mechanics
into repository work: one practical question, a source-grounded mechanism,
material evidence, honest granularity, technical-veracity standing, and an
instruction yield. Private workspace navigation and house notation remain with
their authorized owner.

The next natural uses provide outside evidence for revision. If a skill adds
more routing than capability, fold its useful rules into `AGENTS.md`, the
nearest artifact README, or the source-owning runbook and retire the catalog
entry.

The transaction-boundary route formed after three materially different domain
cycles changed implementation and review decisions. Specimen custody paired
semantic replay with an aligned outbox publication. Instrument ingress added
layered delivery, acquisition, and content identity plus a freshness check
after outside work. Migration cutover added epoch comparison, lifetime
generation meaning, original-approval replay, and post-publication response
recovery. The portable skill retains those operation-level distinctions while
each artifact's source, focused tests, and README retain its domain semantics
and evidence authority.
