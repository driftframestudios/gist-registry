# Registry skills

Registry skills are provisional collaboration affordances. They make a
transferable job easy to discover. Current intent, runnable source, focused
checks, and granted tool authority retain truth, priority, permission, and
evidence roles.

The first skills formed from the registry's initial lived collaboration and
the Practitioner Probe source family:
the [document-evidence artifact](../../snippets/document-evidence-extraction/README.md)
received several bounded architectural vantages, its demonstrated guarantee
became more precise, and accepted `0.1.0` bytes stayed intact. The immutable
`0.1.1` successor now carries the materially stronger source and test
architecture while its manifest records candidate maturity. [Exact excerpt
companions](../../snippets/document-evidence-core-patterns/README.md) make both
accepted behavior boundaries easier to inspect: `0.1.0` carries the initial
same-byte and single-failure patterns, while `0.1.1` carries observed-effect
reconciliation and caller-retained recovery. The skills preserve that
collaboration shape for another team while technical authority stays with the
artifact's source and focused tests.

The first-coordinate formation route carries the transferable probe mechanics
into repository work: one practical question, a source-grounded mechanism,
material evidence, honest granularity, technical-veracity standing, and an
instruction yield. Private workspace navigation and house notation remain with
their authorized owner.

The secret-material route receives an exercised portable contract alongside a
repository-owned implementation. A fresh synthetic canary proves the pinned
reader and sanitized-output path before a named tree, exact index, local-ref
history, or generated artifact receives interpretation.

“Vantage” means a bounded attention instrument specified by a question,
evidence source, observable return, and stopping event. Mechanism-centered
attention supplies the variation. The convergence route releases once another
vantage would leave the selected architecture and receiver unchanged.

The next natural uses provide outside evidence for revision. If a skill adds
more routing than capability, fold its useful rules into `AGENTS.md`, the
nearest artifact README, or the source-owning runbook and retire the catalog
entry.

`transaction-boundary-evidence-mapping` remains an observed candidate rather
than a routing entry. A second materially different domain artifact can wake
it when command fingerprinting, exact replay, changed-intent reconciliation,
state/event/outbox agreement, and injected-failure restoration repeat as one
distinct receiving job. Until then, the specimen-custody source, focused tests,
and artifact README retain the instruction authority.
