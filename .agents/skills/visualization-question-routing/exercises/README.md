# One dataset, three receiving questions

This synthetic exercise applies the skill to eight authored measurements of two
units across two years. The questions ask for within-unit recurring change,
annual association, and exact lookup. The result is three explicit contracts,
not a general chart recommendation algorithm.

With Python 3.11 or later and its standard library:

```sh
python3 .agents/skills/visualization-question-routing/exercises/exercise.py --check
```

The [source CSV](records.csv), [executable exercise](exercise.py), and
[derived contracts](view-contracts.json) travel together. Run the command without
`--check` to regenerate the companion, or add `--output DIRECTORY` to write an
independent copy. The check executes literal expected record selections, exact
lookup values, the highlight/filter distinction, and rejection of a chart-only
contract, then checks exact generated bytes.

An independent reviewer can change the question to "how many observations
support each year?": the fitting result is a count companion with four records
per year. That count describes this fixture's coverage, while completeness of
real observations needs a source-owned recording rule. A second near miss uses
an opaque record ID as chronology; the missing time meaning returns to its
source owner.

The actual receiving task is Issue #52's skill cultivation. Executed assertions
establish these authored selections and the portable package; independent review
and actual figure observations are recorded in the receiving pull request.
General reader effectiveness remains an empirical question. This routing
exercise intentionally ends before rendering; the longitudinal and spatial
packages carry their own produced figures and value companions.
