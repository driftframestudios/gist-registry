# Contextual jargon scan

Use this skill to make durable prose easier to understand while preserving the
technical terms, source language, and compact metaphors that perform real work.

## Fastest start

1. Read the [skill contract](SKILL.md).
2. Name the reader, reading task, files in scope, and one observed word family.
3. Classify each material occurrence as ordinary, exact, source-owned, useful
   compact language, or replaceable shorthand.
4. Revise replaceable shorthand with the smallest concrete object, action,
   relationship, mechanism, or consequence.
5. Use [classification and recovery](references/classification-and-recovery.md)
   when one term crosses prose, code, schemas, quotations, or projections.

## Success example

One passage uses `boundary` for a verified serialization contract and another
uses it for an unclear responsibility change. The scan keeps and locally
defines the exact contract term, then rewrites the second passage to name the
author who supplies the accepted source and the repository that owns runtime
checks.

## Recovery example

A revision removes a required technical distinction. The editor restores the
affected sentence, adds a short definition or concrete example beside the
precise term, and rereads the full paragraph in its receiving representation.
Accepted edits elsewhere remain available.

## Package map

## Evidence maturity and transfer boundary

This is an authored language-review contract supported by contextual cases.
Natural receiving use can establish a local clarity improvement. Broad reader
comprehension, accessibility, search performance, and terminology governance
retain their own observations and owners. Search counts locate candidates;
contextual reading decides each disposition.
