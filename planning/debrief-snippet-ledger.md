# Debrief implementation-companion ledger

Issue #11 established this revisable inventory and closed when its first exact
excerpt companion was accepted. The ledger continues to follow observed source
and visitor needs while each new implementation receives its own Issue owner.

## Selection standard

An effective companion isolates one consequential behavior, supplies or maps
to specification-by-example evidence, and makes its authority, provenance,
failure, and recovery boundaries legible. Recursive or multi-agent
orchestration belongs in examples where coordination is the mechanism being
taught. Domain samples stay focused on their domain behavior.

The source route is:

```text
authorized source reserve
  → human-reviewed public adaptation
  → versioned gist-registry artifact
  → exact GitHub Gist projection when approved
  → accessible visitor excerpt and exact-version link
```

A GitHub Gist is a convenience projection. The registered artifact retains
editable meaning, tests, history, exact-version identity, and recovery
authority.

this ledger begins with domain and collaboration mechanisms whose public
standing is established.
