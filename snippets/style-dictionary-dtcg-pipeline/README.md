# Style Dictionary DTCG pipeline

This family turns reviewed design-token meaning into deterministic files that
front-end receivers can inspect and use. Each version owns its source subset,
compiler coordinate, build matrix, rejection vocabulary, semantic diff,
publication transaction, and recovery route.

## Why this family matters

A token pipeline carries decisions about hierarchy, state, naming, and
ownership. A useful pipeline therefore does more than emit CSS: it admits one
declared format subset, reports the meaning that changed, binds outputs to an
exact compiler coordinate, and moves one accepted pointer after every output
passes review.
