# Document evidence core patterns

This family carries compact, source-mapped excerpts from the complete
[`document-evidence-extraction`](../document-evidence-extraction/README.md)
artifact. Each version selects a small mechanism that can orient a reader near
a Debrief while the comprehensive artifact retains runnable source, focused
tests, fixtures, dependency lock, and recovery authority.

Version `0.1.0` selects two broadly transferable mechanics:

- one byte snapshot supplies both OCR input and the recorded source digest;
  and
- an ownership sentinel and staged promotion preserve accepted output through
  replacement and recovery.

The ordered files under `gist/` form a human-reviewable GitHub Gist candidate.
Repository source remains canonical. A published Gist becomes a convenience
projection of one accepted version and receives its own revision-and-digest
observation after publication.
