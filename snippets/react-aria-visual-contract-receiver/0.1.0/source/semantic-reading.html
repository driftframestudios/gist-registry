Script-independent semantic companion

What the receiver protects

Native HTML and React Aria receive the same visual tokens and domain state. Each layer keeps one bounded responsibility, which makes the interface easier to inspect, test, recover, and replace.

State contract

Draft The visitor’s current stable specimen ID.
Request The draft ID plus a monotonic generation and settlement state.
Accepted The current generation that passed the preview decision.
Released A stable receipt bound to one accepted coordinate.

Settlement and recovery

  • A newer request generation becomes the current settlement owner.
  • A late response returns a stale result and preserves current state.
  • A rejected request preserves the earlier accepted coordinate.
  • A repeated release returns the same receipt.
  • Visible status text announces each current outcome.

Rendering responsibilities

Native route Browser-owned label, select, button, disclosure, focus, and reading order.
React Aria route Headless interaction semantics with stable React Stately collection keys.
Domain model Framework-neutral transitions for draft, request, acceptance, and release.
Token fixture A bounded, provenance-mapped projection of the accepted Acme light token coordinate.
