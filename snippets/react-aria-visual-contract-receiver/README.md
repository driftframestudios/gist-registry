# React Aria visual-contract receiver

This family shows how one accepted design-token coordinate can reach both
native HTML and React Aria controls while the product keeps draft, request,
accepted, and released state explicit. The example favors semantic HTML,
stable collection identities, visible labels, and a small state machine that
can be tested apart from rendering.

## Why this family matters

One visual contract should preserve meaning as it moves from compiled tokens
into controls, async requests, accepted state, and release evidence. This
family keeps those boundaries inspectable across native HTML and React Aria
while a script-independent companion retains the operating explanation.
