# Cross-browser visual-contract observer

## Why this family exists

A visual regression check is useful when its signal matches the decision it
protects. This family makes that match explicit: accessible meaning receives a
semantic oracle, interaction receives an interaction oracle, layout receives
focused geometry, token application receives computed values, and a bounded
visual relationship receives a bitmap crop.

Start with [version 0.1.0](0.1.0/README.md).
