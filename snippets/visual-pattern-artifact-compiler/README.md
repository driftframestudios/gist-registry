# Visual pattern artifact compiler

This family turns one source-owned visual contract into responsive media,
accessible reading companions, and a digest-addressed publication receipt.
The source remains inspectable as JSON, HTML, and SVG while the generated
WebP family carries declared sizes for browser delivery.
